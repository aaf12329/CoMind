## 读完应该带走的三句话

1. 声音不是特殊东西，就是一条采样率很高的序列——你已经会处理序列了。
2. 所有路线共用三件套：**先把声音变成序列（频谱图或 token）→ Transformer/卷积加工 →
   最后都要一个声码器/解码器回到波形**。
3. 现代 LLM 语音模式的核心一跃：声音被 token 化成"一门外语"，之后一切都回到
   你在 04 里已经学过的自回归游戏。
