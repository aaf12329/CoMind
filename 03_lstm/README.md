# 03 LSTM —— 手推 BPTT 的完整版

## 这是什么

字符级语言模型：看前文，预测下一个字符。语料是一句循环出现的话
"attention is all you need. "，训好后它能逐字默写出来——这是最硬的验收标准。

LSTM 是 RNN 治"健忘症"的方案：一条**细胞状态传送带 c** 贯穿时间，
三个**学习出来的开关门**（遗忘门 f、输入门 i、输出门 o）决定记忆留多少、写多少、露多少。

## 它教你的三件事

1. **BPTT（沿时间反传）**：反向传播从最后一个字符的损失出发，时间倒序走回第一个。
   每一步有两条梯度流：`dh`（经隐状态）和 `dc`（经传送带，乘遗忘门跨步）。
2. **梯度裁剪**：BPTT 的连乘会爆炸，`np.clip(±5)` 是 RNN 时代祖传的保命操作。
3. **梯度检查的坑**：纯相对误差判据会在梯度≈0 的条目上假报（分母趋零）。
   正确判据是"大梯度看相对、小梯度看绝对"：`|a−n|/max(1,|a|,|n|)`。
   本仓库踩过的第一个真坑。

## 自测题

1. 为什么 c 这条传送带能治梯度消失？（答：c 每步只做"乘 f＋加新内容"，
   f 接近 1 时梯度几乎无衰减地跨步回流，不像 RNN 每步都乘一遍同一个 W）
2. 反向传播里 `dc_next = dc ⊙ f` 这一行删掉会怎样？（答：梯度检查当场爆炸——
   细胞状态的跨步梯度流断了）
3. 遗忘门偏置为什么初始化成 1？（答：让模型初期倾向"别忘"，先学会记住再学会取舍）
