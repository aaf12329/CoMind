# 豪起来：真男人写代码的方法

> v2 · Python＋JavaScript＋Java 扩展版 · 2026-10-27。原文与参考：本人；结构整理、技术补注与扩写：Codex。

[查看 seed 原文与参考](../seed/真男人写代码的方法.md) · [查看 HTML 排版稿](真男人写代码的方法.html) · [返回阅读索引](../README.md)

首先，我们先抛弃那些花里胡哨的 IDE 或者集成开发环境。

真男人就是应该豪起来。

人生不过三万天，能豪一天是一天。

so 我在此发出宣言：**真男人就该用 notepad 或者 echo。**

编辑器负责写字，解释器、运行时和编译器负责干活。下面就把这几个家伙直接叫出来。

## 01 先召唤小黑框

`Win+R`，输入 `cmd`，回车。想再豪一点，先来一句：

```bat
color 0A
```

本文命令都按 **Windows CMD** 写。PowerShell 的激活脚本、调用方式和重定向规则有区别，先开对黑框。

去代码所在目录，用 `cd /d`，跨盘也一起切过去：

```bat
cd /d "D:\Code\MyDemo"
dir
```

把路径换成自己的。路径带空格就拿双引号夹住；复制程序路径带来的双引号也可以保留。真男人可以不用 IDE，总得知道自己站在哪个文件夹。

## 02 Python：先找到本体

```bat
where python
python -V
```

也可以直接找到 `python.exe`，在资源管理器里复制它的路径。假设本体放在这里：

```bat
"C:\Python3_14\python.exe" --version
```

如果 `where python` 先列出 `WindowsApps\python.exe`，再运行却把你送进应用商店，那可能碰到了应用执行别名。直接点名真正的解释器，少跟它绕。

装过 Python 启动器的，还可以用 `py -0p` 查看它识别的版本，用 `py -3.10` 选择已安装的 3.10。没装启动器就走解释器绝对路径。

## 03 建一个自己的环境

进入项目目录，再开工：

```bat
"C:\Python3_14\python.exe" -m venv myvenv
myvenv\Scripts\activate.bat
python -m pip install 你要的包
```

`myvenv` 建在当前目录。激活后，提示符通常会多出 `(myvenv)`；真要确认当前叫来的是谁：

```bat
python -c "import sys; print(sys.executable)"
```

输出应指向项目里的 `myvenv\Scripts\python.exe`。收工用 `deactivate`。

激活这一步，主要是在当前终端里把环境的程序目录排到 PATH 前面。你也可以直接点名：

```bat
myvenv\Scripts\python.exe Hello.py
```

电脑里可能躺着三个 Python，装包就用 `python -m pip`，省得 pip 把东西装进别的叔叔裤兜里。[Python：venv](https://docs.python.org/3.14/library/venv.html)

## 04 写字与跑路的基础操作

```bat
mkdir demo
cd demo
type nul > Hello.py
notepad Hello.py
```

保存这句进去：

```python
# 无外部输入；由解释器执行，向终端输出一行文字。
print("Hello，小黑框。")
```

再跑：

```bat
python Hello.py
```

基础四件套：`dir` 看这层有啥，`cd 文件夹` 进去，`cd ..` 出来，`cls` 擦干净。

`Tab` 补全，`↑` 翻上一条，`F7` 看历史命令。程序跑飞了先 `Ctrl+C`，别拔电源，那是上个世纪的真男人。

## 05 装包、看家底、换电脑

```bat
python -m pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip list
python -m pip freeze > requirements.txt
```

换电脑先装合适版本的 Python，再创建、激活新环境，然后：

```bat
python -m pip install -r requirements.txt
```

这能恢复清单里的 Python 包；系统库、驱动和外部服务还得另配。`myvenv` 就别整个塞网盘了，交代码、必要数据、依赖清单和运行说明，别交半个硬盘。

## 06 echo 一把梭

```bat
echo print^("Hello CMD"^) > Hello.py
echo print^("Still here"^) >> Hello.py
type Hello.py
python Hello.py
```

`>` 覆盖，`>>` 追加。括号、`&`、`|`、`%` 等字符要结合 CMD 的解析和转义规则处理。写长代码还是 `notepad 文件名`，省下来的命拿去写功能。

中文乱码可以先试 `chcp 65001`，但它改的是当前控制台代码页，**不会把已有文件自动变成 UTF-8**。`echo` 重定向的编码也受运行方式影响，别一口咬死永远是 GBK。中文代码文件直接在编辑器里保存为 UTF-8，更省事。

报错从最后一行的异常类型和提示开始看，再顺着堆栈回到自己的文件与行号。最后一行给线索，上面有案发现场，不能只看一句就结案。

## 07 JavaScript：把 Node.js 叫出来

先看看人到了没有：

```bat
where node
node --version
npm.cmd --version
```

直接输入 `node`，会进入交互式解释环境 REPL。敲 `1 + 1` 试试，输入 `.exit` 回到 CMD。[Node.js：REPL](https://nodejs.org/learn/command-line/how-to-use-the-nodejs-repl)

要写文件就 `notepad New.js`，保存下面这份：

```javascript
/*
主题：用 Node.js 执行脚本；无外部输入。
结构与调用树：文件入口 → main → Device.constructor / Device.showName。
数据流：字符串 "X220" → device.name → 终端输出。
运行：node New.js；只用标准运行时，不需要第三方包。
*/
class Device
{
    constructor(name)
    {
        this.name = name;
    }

    showName()
    {
        console.log(this.name);
    }
}

function main()
{
    const device = new Device("X220");
    device.showName();
}

main();
```

在文件所在目录运行，输出 `X220`：

```bat
node New.js
```

没配 PATH 也能直接用绝对路径。下面以本机的位置举例：

```bat
"C:\nodejs\node.exe" New.js
```

就这么叫。一个只用运行时本身的脚本，连 `npm init` 都不用先来一遍。[Node.js：从命令行运行脚本](https://nodejs.org/learn/command-line/run-nodejs-scripts-from-the-command-line)

## 08 HTML 带 JS：先把网页搭起来

网页里的 JS 交给浏览器执行。先建一个文件夹，放这两个文件：

```text
web-demo/
├── index.html    浏览器读取的页面
└── app.js        页面加载后执行的 JS

数据流：浏览器请求 HTML → 解析页面 → 加载 app.js → main 修改页面文字
调用树：浏览器执行 app.js → main → document.getElementById（浏览器 API）
```

`index.html`：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>小黑框网页</title>
    <script src="./app.js" defer></script>
</head>
<body>
    <p id="message">等 JS 开工。</p>
</body>
</html>
```

`app.js`：

```javascript
/*
主题：浏览器加载脚本，更新一段文本。
输入：index.html 中 id 为 message 的元素。
调用树：脚本入口 → main → document.getElementById（浏览器 API）。
数据流：固定字符串 → 元素的 textContent → 页面显示。
运行：浏览器打开配套页面；defer 让脚本在 HTML 解析后执行。
*/
function main()
{
    const message = document.getElementById("message");
    message.textContent = "浏览器里的 JS，开工。";
}

main();
```

普通的简单页面可以先双击 HTML 看。但模块、资源请求等场景有浏览器的来源限制，开个本地 HTTP 服务会更接近网页正常运行的环境。这里的 `document` 来自浏览器；把 `app.js` 直接丢给普通 Node 脚本运行，会遇到 `document is not defined`。[Node.js：与浏览器的区别](https://nodejs.org/learn/getting-started/differences-between-nodejs-and-the-browser)、[MDN：script 与 defer](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/script)

## 09 开 HTTP 服务：把当前文件夹递给浏览器

先 `cd /d` 进入 `web-demo`。原始参考命令是：

```bat
npx.cmd http-server . -p 8000 -c-1
```

这会借 Node.js 启动第三方工具 `http-server`。本篇固定使用 14.1.1，并明确只监听本机回环地址：

```bat
npx.cmd http-server@14.1.1 . -p 8000 -c-1 -a 127.0.0.1
```

- `npx.cmd`：执行 npm 工具；缺少对应包时可能提示下载，首次使用需要网络。
- `http-server@14.1.1`：工具名和固定版本。`http-sever` 少了一个 `r`，npm 可不会替你猜。
- `.`：把当前文件夹作为服务根目录；换成指定目录，也能从别处启动。
- `-p 8000`：监听 8000 端口。手动选端口用 1～65535，80000 就别写了。
- `-c-1`：关闭这个服务的缓存设置，方便调试；它不会替你把浏览器里已有的所有缓存清空。
- `-a 127.0.0.1`：只接受本机访问。本篇用它看自己的网页。

参数和默认页面行为见 [http-server 项目说明](https://github.com/http-party/http-server)，包的查找和执行方式见 [npm：npx](https://docs.npmjs.com/cli/v11/commands/npx/)。

服务窗口先留着，浏览器打开 `http://127.0.0.1:8000/`。也可以另开一个 CMD：

```bat
start "" "http://127.0.0.1:8000/"
```

请求 `/` 时，工具会优先提供目录里的 `index.html`。想看别的文件就直接访问 `http://127.0.0.1:8000/其他文件.html`。服务根目录由传入的路径决定；监听地址决定从哪里能连接，两个参数管两件事。

```text
CMD → npx → Node.js 运行 http-server → 监听 127.0.0.1:8000
浏览器 → GET / → 服务读取 index.html → 返回页面
浏览器 → GET /app.js → 服务返回 JS → 浏览器执行 JS、更新页面
```

这个服务负责传文件。它不会替你执行页面里的 JS，更不会因为目录里有 `.py`、`.java` 就顺手把它们跑起来。端口占用就换成 8001，访问地址也跟着改；收工在服务窗口按 `Ctrl+C`。

### 已经有 Python？也能开

```bat
"C:\Python3_14\python.exe" -m http.server 8000 --bind 127.0.0.1
```

同样先进入网页文件夹，再访问刚才的地址。这是 Python 标准库的另一个服务，参数跟 npm 那个工具各算各的，别把 `-c-1` 搬过来。两条路选一条，别抢同一个端口。[Python：http.server](https://docs.python.org/3.14/library/http.server.html)

## 10 Java：编译器和运行器分开点名

Java 的原始参考就是这两句，本机 JDK 放在 `D:\JDK`，没有配置 Java 的 PATH：

```bat
"D:\JDK\bin\javac.exe" New.java
"D:\JDK\bin\java.exe" New
```

先进入保存 `New.java` 的目录。`javac.exe` 把源代码编译为 `.class` 字节码；`java.exe` 启动 JVM，再加载入口类。**`New` 是类名，注意大小写。**

先用 `notepad New.java` 写下面这份，保存为 UTF-8：

```java
/*
主题：用 JDK 编译并运行一个类；无外部输入。
结构与调用树：JVM → New.main → System.out.println（标准库）。
数据流：固定字符串 → 标准输出 → 终端。
运行：javac -encoding UTF-8 New.java，然后 java -cp . New。
*/
public class New
{
    public static void main(String[] args)
    {
        System.out.println("Java，小黑框开工。");
    }
}
```

明确指定源码编码和类查找位置，来一套：

```bat
"D:\JDK\bin\javac.exe" -encoding UTF-8 New.java
"D:\JDK\bin\java.exe" -cp . New
```

`public class New` 对应文件 `New.java`；这里没有写 `package`。`-cp .` 表示到当前目录找类。运行编译产物时写 `New`，不要写 `New.class`。[Oracle：javac](https://docs.oracle.com/en/java/javase/25/docs/specs/man/javac.html)、[Oracle：java](https://docs.oracle.com/en/java/javase/25/docs/specs/man/java.html)

```text
New.java → javac -encoding UTF-8 → New.class → java -cp . New → New.main → 终端
```

想把编译产物另放一个目录：

```bat
"D:\JDK\bin\javac.exe" -encoding UTF-8 -d out New.java
"D:\JDK\bin\java.exe" -cp out New
```

源代码改了，就重新编译。编译失败先处理错误，别接着跑旧 `.class`，然后怀疑自己刚才改了个寂寞。

### 懒得总敲绝对路径？当前窗口临时加 PATH

```bat
set "PATH=D:\JDK\bin;%PATH%"
javac -version
java -version
```

这条 `set` 只影响当前 CMD 及它之后启动的子进程。关掉窗口就没了，正适合临时干活。

现代 JDK 还支持源码文件启动模式，例如这份单文件小程序可以用 `"D:\JDK\bin\java.exe" New.java` 直接启动。那是另一个启动模式，仍涉及编译；先把上面的两步看明白，再偷懒也不迟。[Oracle：源码文件启动模式](https://docs.oracle.com/en/java/javase/25/docs/specs/man/java.html#using-source-file-mode-to-launch-source-code-programs)

## 11 把三个家伙摆一排

```text
Python 脚本：   python.exe → Hello.py → 终端输出
Node.js 脚本：  node.exe → New.js → 终端输出
浏览器网页：    HTTP 服务 → HTML / JS 文件 → 浏览器执行 → 页面变化
Java 程序：    javac.exe → New.class → java.exe → New.main → 终端输出
```

工具找不到就检查 PATH，或者直接写程序绝对路径；文件找不到就看当前目录和文件名；端口占用就换端口；页面没变就看看请求的文件、控制台报错和缓存。

把这几个东西认清楚，以后 IDE 帮你按按钮时，你也知道它在背后叫谁干活。
