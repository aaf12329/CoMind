# AI竞争与我的工具箱

> 把模型拉出来干活，也让普通人干得起活。

## 一、这场竞争，怎么就让我用爽了

聊中美 AI 大战，我最直接的感受其实很粗暴：你们继续打，把东西做好，把价格打下来，我这里还有一堆项目等着干。

我有时候觉得，中国模型总是在后面追，做开源的次旗舰，新一代能和对面的上一代旗舰打得有来有回就行了。但这话拿来吐槽可以，真给所有模型排一个永远不变的座次，也没什么意思。我关心的是手头这件事，谁能做、多少钱、我能不能用得起。

我忘不了 26 年那个夏天。按我当时的记忆，DeepSeek、Kimi 在往前挤，Gemini 有学生优惠，GPT 也能找到更便宜的使用机会，Claude 的使用限制给我的感觉也没那么紧。具体型号和活动现在回头看得重新核对，但那个感受很清楚：可选的东西突然多了，尝试的成本降下来了。woc，爽飞了。[^1]

你可以在网上吵半天哪个模型强。我这边的反应是：现在能不能多跑一轮？能不能把上次没舍得研究的东西再拆开看看？

便宜的 Token 对我有用，就有用在这里。它让我敢把一个问题问到底，敢让 Agent 改错以后再跑一次，敢拿同一个方案做几组对照。东西搞砸了，损失还在能接受的范围里，那就继续改。

**技术的价格，决定了多少人能真的下场试。** 这个变化，比一张排行榜更容易落到我的电脑上。

## 二、我这里有东西，拿出来看

我有一个[个人网站](http://47.111.117.24/)，这玩意就是靠 6.1 Sol 搭起来的。页面写着“把好奇心，做成能运行的东西”，旁边挂着我的 [GitHub 项目](https://github.com/aaf12329)。网站能打开，代码和学习记录也有地方放，这就是一个具体的落点。[^2]

当然，网页打开只算第一步。链接有没有断，项目介绍和仓库对不对得上，换个设备看是不是挤成一团，部署以后还能不能维护，这些还得一件件看。写出页面只是整个流程中的一段。

再比如我自己折腾的 [My_Agent](https://github.com/aaf12329/My_Agent)。最开始就是聊天机器人，后来想接 Prompt、记忆、工具。真往下做，问题马上就来了：聊天记录和长期记忆放不放一起？模型什么时候调工具？工具结果怎么塞回去？它要是一直调下去，谁给它踩刹车？[^3]

说点专业的，这叫工具调用循环：模型提出调用，程序执行，把结果回传，再让模型判断下一步。话说完就这么一句，写进代码里，异常、权限、状态、退出条件全得管。

我就喜欢把这种东西拆开看。API 能回话以后，后面还有这么多层，够研究了。

还有[材料吸附建模那一套](https://github.com/aaf12329/WGAN_Boost_Xgboost)：生物炭、污染物吸附、XGBoost、CatBoost，数据少了又去折腾 WGAN。仓库里连普通 GAN 失败的对照都留着。那个搞死人地 GAN，跑起来和生成得像样，中间还隔着一堆问题。[^4]

这些项目有研究，有练习，也有技术验证。学会一块，先停在那里；下次碰到新问题，再把它接起来。项目做到哪一步，就按哪一步算账。验证一个工具调用循环，和做成能长期运行的产品，验收标准当然不一样。

所以，模型降价给我的东西很具体：我能多验证几个想法，多拆几层结构，多留下几份下次还能接着用的代码。

## 三、我的工具箱，就是这么拼起来的

我现在会把 GPT、DeepSeek、GLM、WorkBuddy、Gemini 放在一起用，另外还有本地的小模型。它们各有各的位置。原文里那些月费、学生优惠、节假日赠送，都是我当时怎么用起来的记录，别拿这篇当长期有效的套餐清单。[^1]

DeepSeek 这玩意，我喜欢它便宜。尤其是 API，按实际输入、输出的 Token 算调用费用。[^5]

为什么我会推荐这种方式？很多人一个月就用几天，你直接包月，钱先交出去，后面一直闲着。你就想想：你付他一个月工资，他只干三天活，你觉得划算吗？

**不干活就可以不给调用费，干活才给钱。** 对我这种有时候集中折腾、有时候暂时放下的人，这种计费方式就很顺手。当然，真连续大量用起来，得把总量算一遍，包月和按量谁便宜，看实际账单。

GLM、Zcode 那边，节假日送 Token 的时候我也用得很爽。工具环境已经搭好，额度又给了，那就把项目拉出来干。

就算拿我的代码，我都认了。我一个字符串匹配与压缩的 C 代码都写不利索，项目还是开源的，里面还有猎奇注释和一堆屎山。你想拿就拿吧，反正我没意见。

但这只是我对自己这份代码的态度。代码开放到什么程度、别人拿去能做什么，得把许可和说明写清楚。技术信息能流动，我很欢迎；把别人的选择一起替他做了，那又是另一件事。

Gemini 也是，有合适的使用机会就拿来试。至于本地，我还跑声音克隆和视频生成模型，一个拿角色语音整活，一个试试自媒体。不同的东西解决不同的问题，能接起来就接，暂时接不起来就先放着。

## 四、模型这么多，得有个干活的顺序

我现在的安排大致是这样：先用 GPT 6.1 Sol 讨论架构与方向，再用 GPT 6 Astra 做项目框架规划和模型分工；具体写代码、改代码交给 DeepSeek，做完再让 Sol 检查、测试，有错交回 DeepSeek 反攻，之后和 Astra 继续讨论架构调整。

这套安排里，我最在意的是每一轮有没有明确产物。

讨论架构，就把模块职责、接口、输入输出说清楚。具体实现，就交出能运行的代码。检查的时候，就拿实际命令、测试结果、差异和失败原因出来。别开完一个会，再开一个会，最后文件夹里什么也没有。

进了项目，也别拿省 Token 当成绩。该测试就测试，该把证据拿齐就拿齐。为了省几次调用，让我来回解释五遍，省了个寂寞。低价让我进得去，协作效率决定我愿不愿意继续用。

换模型检查也有用，但模型多了以后，互相点头这件事仍然可能发生。三个模型说没问题，程序该报错照样报错。它们可以帮忙找问题，最终还得把东西拉起来跑。

我桌面上那个产业信息研究平台，就有一份很适合拿出来看的记录：同一批 26 个公开来源，整理后两条处理路径分别拿到 26 个和 25 个年度数据点，XGBoost 也确实进入了建模流程。

然后呢？两条路径的测试误差，都明显大于“直接沿用上期数值”这个简单基线。[^6]

这就很有意思了。前面采集、清洗、建模、出图，流程跑了一大圈，最后被一个“先用去年那个数”的办法打了。那就老老实实记下来：这一轮预测不可靠，别拿它装成趋势结论。

**程序运行成功、模型预测有效、结果能够支持判断，这是三件事。** 你不把它们分开，流程越漂亮，越容易把自己骗进去。

这么看，我的 Token 还有余裕；我的验收标准也得跟着长。便宜可以让我多试，试出来的东西到底怎么样，得继续核对。

## 五、企业该挣的钱挣，别把人当耗材

我对有些企业的吃相很不满。这种不满，和我喜欢便宜模型可以同时存在。

我会比较不同地方的企业、劳动保障和做事标准，也确实觉得一些更成熟的保障与标准化做法值得学。但要认真比较，行业、岗位、保障到底落不落地，都得拆开看。拿几个新闻就给所有企业定性，骂得痛快，后面的解释还没做完。

我说需要一个“看起来文明的领导者”树立榜样，想要的其实很具体：你有本事把技术做强，也有本事把对人的基本尊重做出来。

工资该付就付，劳动该尊重就尊重，出了问题能追问，宣传过的能力能核对。别把“技术领先”当成所有问题的通行证。

这里面当然有成本。更好的劳动条件、更扎实的工程、更稳定的服务，都得有人付账。我也得问一句：我手里这个低价，到底靠的是效率提高，还是把成本推给了某个没法说话的人？不同企业、不同产品得拿各自的材料说，不能看一眼价格就下结论。

但成本存在，也不能变成什么都不用改的理由。企业已经敢给自己画那么大的未来了，对人的基本要求，也该往上提一提。

我做工程时会要求日志、结果和责任能追得回去。看一家企业，我也希望能问同样的问题：你说做到了，证据在哪里？出了问题，谁处理？

## 六、我想让技术流动，也想把边界说清楚

我觉得王兴兴和我在理念上有相似的地方，我向往那种理想主义极客的方向：技术能做出来，也能让更多人接触到。具体一个人、一家企业怎么行动，还得看具体的事。

我的技术和他们差很多，这个没什么不好承认的。我一个 C 的小程序都能写出一堆问题，但我照样可以把学习记录、失败对照、项目结构放出来。

有人看到一个仓库，能少绕一个弯；看到一个失败实验，知道这条路已经有人撞过；看到一个能启动的项目，敢在自己的电脑上改两行，再让它跑起来。这些就已经有用了。

我的主页、CoMind 和那些练习项目，对我来说就是在做这件事：把理解留下来，让后面的人有东西可看，也让我自己下次能接着干。

我会说“AI 本质就是在蒸馏人类”。这句话有我的情绪和比喻在里面。真到技术上，知识蒸馏有它自己的训练方法；真到具体数据怎么取得、作品怎么使用，也得看具体行为。不能拿一句大话把所有问题全糊过去。[^7]

我愿意让自己的东西流动，也愿意把自己的选择说清楚。别人愿意开放，尊重；别人有边界，也尊重。这样流出去的技术，才接得住、用得下去。

## 七、继续打，我这里还等着开工

至于中美 AI 竞争，我还是那个很粗暴的态度：继续打，把模型往前推，把调用成本往下压，把工具做得更好用。

谁能让我把一个想法更快地落进文件夹，变成能运行、能检查、能接着改的东西，我就愿意用谁。

我不希望最后只剩一家，也不希望普通人只能隔着价格、额度和一堆接入门槛，看着技术在上面转。

我希望看到的进步，是我打开电脑以后，真的多了一件能做的事。能搭个网站，能拆一个 Agent，能跑一轮实验，也能在发现结果不行的时候，老老实实承认它不行。

你们竞争得越有本事，我这里能试的东西就越多。

行了，别光打榜了，把东西拉出来干活。
