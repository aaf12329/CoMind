# 给新生的建议

> 原文加注版：保留原有顺序、措辞和例子，仅重新分段；补充说明集中在文末。

总之不要去网上找教程没啥卵用效率太低我的建议是一个Agent+图吧工具箱直接就是干，先做再说大不了做错了就删掉，这样才是最快的还有别抱着那个糖的死的豆包这玩意也就配修修图了[^1]

对于计算机电子电气以及一切粘代码方向的大学生我的建议是在大学前两个月不要天天抱着你这破豆包。

至少先分个工，代码，数学问题可以给到网页版的DeepSeek，读论文不论是中文还是英文都丢给Kimi(不要过分依赖Kimi有时候他会服务器过载无响应)

之后就是接触一下Agent了，这才是人工智能真正的完全体，根据你前两个月的使用量或者依赖程度去选择模型，现在国模的几个方向就是DeepSeek与GLM争夺国模一哥，然后KIMI与QWEN稳步跟进，

如果你用量不大不直接全部那这玩意做项目就直接DeepSeek 的API就行了就是把DeepSeek接入Zcode里面（为啥用Zcode？因为这玩意不会像DeeoSeek原生的Agent一样要自己配插件而且节假日会送Token免费用可以白嫖反正我是用爽了国庆节一天送一亿Token我研究完了CatBoost与Xgboost，把WGAN打包成了标准训练体系，搓了一个简单的Agent，初步入门了现代的web与Electron总之给我用爽了）

为什么我会这么推荐 DeepSeek API？因为很多人一个月就用几天，直接月付不划算。你就想想，你付他一个月的工资，他只干三天活，你觉得划算吗？DeepSeek API 的好处就是：不干活就可以不给钱，干活才给钱。[^7]

如果用的多可以搞一个GLM的套餐118一个月的（当然国际版的WorkBuddy可以白嫖DeepSeek）（我只能说你是吃这碗饭的你得为这玩意花点钱）

然后在软件方面先下载一个git（这个是中小型公司的代码协作版本控制器，大公司内部用的大概不一样但是逻辑大差不差）[^2]如果可以访问国际互联网就注册一个Github这是全球最大的代码开源网站，多看看总是有好处的，计算机是最需要与时俱进的，很多其他的东西知识几十上百年不变但是计算机可能几年或者几个月就把一个技术淘汰了

然后技术方向就是先C加上Python  C是在训练你的工程思维，Python带你入门类与对象。

之后你要搞AI就是去学机器学习以及其他的，想做网页或者网站开发就是前端三件套HTML，CSS，JavaScript，然后再看看TypeScript。就去学架构前端React,Vue，后端Next.js[^3]硬件方向找B站江科大51，32然后再自己找方向。

如果可以试一下20$/月的GPT然后不要全部交给GPT，得让GPT指挥GLM或者DeepSeek干活（主要是Claude会封号这得搞海外服务器门槛比较高）
对于生物化学之类的方向我的建议是上DeepSeek的API+Zcode然后有什么好点子多和计算机这一类的合作一下。
对于文科生：拿WorkBuddy干干活然后用Kimi读一下文档（kimi的文本能力是真的好用如果开会员也就一个月50￥）


AI是一个变革时代的东西，上一个这种东西叫做计算机与通信技术，他们都有一种共同的性质，一个隐秘的变化：他们改变了信息的传输的速度，在底层来看是带宽，延迟，丢包率。[^4]这虽然无法直接的影响现实世界的东西但是它提高了协作以及博弈的速度或者说透明度，信息不再是被束之高阁，专业之间的壁垒也不再是叹息之墙，而是变成了人人可以接触到的东西，技术的信息可以平等的流向每一个人。甚至它还可以看出什么是错误的，什么是正确的，根据现有的错误信息推导出正确信息（我的学习路径覆盖web，软件，硬件，算法）

在进行表格数据（对就是excel但是后缀是.csv反正也可以理解为excel就对了）[^5]清洗的时候我们会先把它扔进一个模型里面标记出什么地方是不合理的，假设一类产品的工作电压是5V但是在表格里面出现了220V就是异常值了，这时候我们就要去标记，核对，（至于为啥不用人…………动不动几千条数据起步你用人来清洗是不是有点太那啥了还不如直接扔给算法又快又准）然后就是根据其他数据的特征去拟合这个异常数据（一般是平均值行话叫KNN填充）[^6]但是现在全都扔给Agent（你们理解为可以在电脑上自己干活的AI可以直接操纵你的电脑）

但是我是有点守旧的我仍然坚持术业有专攻，我是的算法方向是研究生物炭环境治理的，很多问题我仍然是扔给Xgboost与CatBoost（现在就只是在研究这俩由于训练数据不够还得搞那搞死人地GAN模型）

## 注释

[^1]: 工具评价和模型座次是个人使用感受；月费、赠送额度及账号条件具有时效性，按各家官方当前说明核对，不能把“海外服务器”当作通用前提。

[^2]: Git 是分布式版本控制工具，也用于大型项目，并不限于中小公司。[Git 官方介绍](https://git-scm.com/)

[^3]: Next.js 是基于 React 的全栈框架，不能仅把它理解成“后端”。[Next.js 官方说明](https://nextjs.org/docs)

[^4]: 这里的带宽、延迟、丢包率可以理解为信息获取和协作效率的类比，不等于 AI 直接改变了通信链路的物理带宽。

[^5]: CSV 是表格文本格式，可以用 Excel 打开，但不是 Excel 工作簿。5 V 与 220 V 的差异，也要结合设备、字段和单位核对后再判定。[CSV 格式说明](https://www.rfc-editor.org/rfc/rfc4180)

[^6]: 均值填补与 KNN 填补不是同一种方法：KNN 根据可用特征找近邻，再利用邻居的相应数值估计缺失项；填补值不等于找回真实测量。[scikit-learn 说明](https://scikit-learn.org/stable/modules/impute.html)

[^7]: 这里的“干活才给钱”指模型 API 按实际输入、输出 Token 用量计费，不是按任务是否成功收费；是否比月付划算，要看实际用量。[DeepSeek 官方计费说明](https://api-docs.deepseek.com/quick_start/pricing/)
