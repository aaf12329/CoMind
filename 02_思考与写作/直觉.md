# 一种神奇的感觉

> 📝 **思考笔记** —— 关于「AI 为什么没有人的感觉」，以及「怎么往它身上人为制造一点」
> 来源：chatbox 项目废案（草稿纸） · 整理：2026-10-04 · 状态：**构思中，未验证**

---

## 0. 核心观点（含判定）

> AI 的思维链路在**方向性**上已经很像人类了——连"幻觉"都像；
> 缺的是人类思维链路的**抽象**与**发散**。
> 我的方案：**不单给相关上下文，还随机抽取一些弱相关甚至无关的 prompt 与记忆强行注入——
> 把那些本来会被优化掉、剪掉的搜索路径，强行撑开。**

判定图例：✅ 有依据站得住 · ⚠️ 部分成立，需修正 · ❓ 猜想，待验证

| # | 观点 | 判定 | 一句话依据 |
|---|---|---|---|
| 1 | AI 与人类思维链路在"方向性"与"幻觉"上同构 | ✅ | 幻觉≈confabulation（脑补衔接），两侧机制描述同构；人类记忆同样靠编合理情节糊断点 |
| 2 | 缺口=抽象与发散，可翻译为"搜索路径宽度" | ✅ | Mednick 联想平坦度理论（§8-1）：创造力=弱联想也能被激活，正牌出处 |
| 3 | 迷宫/剪枝模型 | ⚠️ | 当心智模型好用，但机制描述要修正：Transformer 没有持续被剪枝的"路径"，注入实际干的事是**给下一个 token 的概率分布加料**（逐 token 重算注意力） |
| 4 | 随机注入能拉开被剪掉的搜索路径 | ⚠️ | "路径多样性有用"已被证明（§8-3 Self-Consistency）；但"均匀随机"应改为**相似度中间带的远距离注入**（0.2~0.45 分位），纯噪声只贡献稀释（§8-4） |
| 5 | 小模型路径扩散小，最需要注入 | ⚠️ | 对一半：小模型联想层级确实更陡，但也**最不会利用弱相关上下文、最容易被带偏**——病最重的病人对药最不耐受。可检验预言：同方案强模型增益为正，弱模型可能为负 |
| 6 | 幻觉 = 剪不干净的发散残渣 | ❓ | 全文最弱一环，目前更像诗而非机制；严谨但平庸/幻觉/创造或是同一套宽搜索的三种命运，交 §7 实验裁决 |

**总判定：方向大体正确，是值得做实验的好假说——不是"正确的东西"。按 ⚠️ 项修正设计后即可动手（§7）。**

## 1. 问题：强，但不像人

现在 AI 很多东西比人类强很多，但仍然没办法给人一种"人"的感觉。

| | AI | 人 |
|---|---|---|
| 知识面 | 碾压 | 只记得住自己踩过的坑 |
| 速度/耐力 | 碾压 | 会累、会降频 |
| **方向性**（朝结果逼近） | ✅ 有 | ✅ 有 |
| **幻觉**（一本正经地编） | ✅ 有 | ✅ 也有 |
| **抽象**（跨域的、非数学的） | ❌ 弱 | ✅ 强 |
| **发散**（不朝结果的游走） | ❌ 被压制 | ✅ 强 |

矛盾的点就在这：前两行说明链路结构是相似的，后两行说明相似到此为止——
**"神奇的感觉"恰恰住在后两行里。**

---

## 2. 像的部分：方向性与幻觉

AI 的思维链路展现出来了与人类类似的方向性——**就是根据结果的方向逼近**。
梯度下降是朝 loss 变小逼近，人的思考是朝"想要的东西"逼近，链路形状是同一类。

也与人类一样有所谓的"幻觉"：人的记忆本来就会脑补——虚假记忆、记错细节、
把两次经历缝成一次，都是"编一个合理的衔接"把断掉的地方糊上。
AI 幻觉在机制上像极了这件事，所以**幻觉本身不能作为"不像人"的证据**，
它反而是"链路同构"的旁证。

---

## 3. 不像的部分：抽象与发散

这里的"抽象"**并不是抽象成数学模型这个抽象**，而是人类那种跨域的、
带隐喻性质的抽象：

- 把两个不相干领域的东西捏到一起，还真能捏通（"GAN 就是两个 MLP 左脚踩右脚飞天"）；
- 把复杂概念剥到最基础的形式，再换个领域重新组装；
- "积分度量过去，求导张望未来"——纯跨域类比，没有任何数据集教过。

发散则是**不朝结果逼近的游走**：走神、白日梦、洗澡时的灵光一闪。
从"收敛到答案"的角度看这些全是浪费，但创造几乎都从这里来。

**关键：抽象和发散不是两种能力，是一件事的两面——都要求搜索路径"变宽"，而不只是"变准"。**

---

## 4. 迷宫模型（把思考过程抽象为在巨大迷宫里找东西）

这个问题我在 chatbox 项目的废案中（草稿纸上）就构思过：一开始构思的是
**记忆库向分层量化**与 **Prompt 向量化**，往后推一步就撞到了这里。

把思考过程抽象为在一个巨大的迷宫中找寻东西：

- 目标物**可能是一个**，放在一个地方；**但更多时候是多个**，分散在多个不同的位置，
  甚至看起来毫不相干的位置；
- 思考 = 路径追踪；**优化 = 剪枝**：相关性低的分支在追踪过程中会被忽略掉、被优化掉；
- **尤其是小模型——参数小，路径扩散也小**。参数量约等于"同时养得活的并行假设数"，
  小模型养不起宽搜索，剪枝下手更狠。

```
            常规优化后的搜索
             问题输入
                │
      ┌─────────┼─────────┬─────────┐
      ▼         ▼         ▼         ▼
    分支A      分支B      分支C      分支D
   (高相关)   (中相关)   (弱相关)   (看似无关)
      │         │        ✂ 剪      ✂ 剪
      ▼         ▼
      └────答案（收敛）────┘
```

人类在这里的优势：剪枝下手轻，分支 C、D 还活着——所以人能"莫名其妙想起一件事"，
能把两件不相干的事连上。AI 的剪枝下手太准、太狠，路径宽度被优化掉了。

---

## 5. 方案：随机注入（给被剪掉的路径强行续命）

**不单单给相关提示词与记忆（或者说上下文），也会用随机抽取的方式，给一些相关性不高
甚至不相关的 prompt 与上下文——强行拉开一些本来会被优化的搜索路径。**

结构上就是给常规 RAG 加一路"噪声源"：

```
 用户输入 ──▶ 相关检索（常规 RAG/向量库 top-k）──┐
                                              ├──▶ 按比例混合 ──▶ 模型
 随机抽取（记忆库低相关分位/旧对话片段/随机话题池）──┘
```

几个可以对接的理解锚点：

| 已有概念 | 在输出端/训练端做的事 | 本方案对应 |
|---|---|---|
| temperature / top-p 采样 | **输出端**加随机 | 本方案相当于把随机搬到了**输入端/记忆层**——"输入端的 temperature" |
| 模拟退火 | 故意接受劣解，跳出局部最优 | 随机注入 = 给搜索过程喂"劣解"，防止过早收敛到最平庸的答案 |
| beam search 剪枝 | 只留 top-k 路径 | 分支 C、D 正是被 beam 剪掉的那类；注入 = 强行把 beam 加宽 |
| 人类走神（白日梦） | 无目的记忆投放 | DMN 式随机投放，本方案就是人工版 |

**设计草案（待定参数）：**

| 参数 | 候选做法 |
|---|---|
| 注入源 | 向量化记忆库中相似度**低分位**的条目、被压缩掉的历史对话、完全随机的旧笔记 |
| 抽取比例 | 从 5%~10% 起试；应存在一个"倒 U 型"最优值——太少没用，太多稀释注意力 |
| 注入位置 | 偏好放开头/结尾（中段容易被"lost in the middle"忽略） |
| 任务开关 | 创造性任务（类比、头脑风暴、方案设计）开；事实型任务（查数据、写代码）关 |

**已知风险（先记下来）：**

1. **注意力稀释**：无关上下文会摊薄模型对真相关内容的注意力，等于上下文污染；
2. **成本**：白花 token，比例和截断要控制；
3. **幻觉加重**：本来就是往"编"的方向喂料——见下一节的猜想。

---

## 6. 一个顺手牵出来的猜想

> **幻觉也许不是 bug，而是被剪枝剪得不干净的发散残渣。**

同一套宽搜索机制：剪枝干净利落 → 看起来"严谨"但毫无创造力；
剪枝剪不干净 → 幻觉；剪枝之后有人接着往下走并验证 → 创造与跨域联想。
三者可能是同一个东西的三种命运。随机注入想做的，就是主动制造第三种。

---

## 7. 下一步（可验证的最小闭环）

1. **复活 chatbox 废案**：记忆库分层量化 + prompt 向量化 + 本方案的随机注入层，
   三件事正好是同一条线上的三段；
2. **A/B 对照**：纯相关 RAG vs 相关 + 5% 随机注入，分两组任务测——
   创造性任务（跨域类比、头脑风暴）与事实任务（问答准确性）**分开看**；
3. **扫比例曲线**：注入比例 0% → 2% → 5% → 10% → 20%，预期创造性指标先升后降（倒 U），
   事实指标单调下降——找到两族曲线的交点附近就是可用的工作区。
