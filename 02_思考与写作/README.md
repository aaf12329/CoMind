## 文件怎么区分

- **思考笔记**保留想法提出时的措辞、猜想或阶段性整理，不自动视为已证实结论。
- **文章版**将想法组织成便于阅读的叙述，包含相应论据、参考资料与适用边界。
- **TXT 版本**保留已有的纯文本阅读形式；链接呈现可能与 Markdown 不同，需要修改时按需同步。

原始笔记与文章之间可能存在修正或不同说法，阅读时结合各自的写作阶段判断。本目录整理不代表重新核验了文章中的全部科学主张与引用。
