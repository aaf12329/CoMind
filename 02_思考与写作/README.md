## 两份文件怎么维护

- **seed 保留本人原文。** 原始猜想、措辞和笔误不由润色稿反向覆盖；文件开头注明来源。
- **articles 面向阅读。** 默认贴近 seed 原文，只做适量排版、润色与必要注释；大幅扩写按本人明确要求进行。补充内容与原话分开，文章的修正不等于原文早已包含相同结论。
- 新主题使用同一主题名，例如 `seed/新主题.md` 对应 `articles/新主题.md`，并在本表补充一行。保留 HTML 排版稿时，配对文件可为 `seed/新主题.md` 与 `articles/新主题.html`。
- 同一篇成稿同时提供 Markdown 与 HTML 时，正文以 Markdown 为准，HTML 同步更新排版；两份成稿属于同一主题。
- 只有原文时先放入 `seed/`，文章栏标注“待整理”，不创建空白文章或失效链接。
- Markdown 文件提供返回目录及已成文主题的配对入口；保留原样的 HTML 稿通过本索引配对，seed 也直接链接 HTML。正文中的具体主张仍须结合来源及写作阶段判断。
