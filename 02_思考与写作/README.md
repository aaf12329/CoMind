## 两份文件怎么维护

- **seed 保留本人原文。** 原始猜想、措辞和笔误不由润色稿反向覆盖；文件开头注明来源。
- **articles 面向阅读。** 默认贴近 seed 原文，只做适量排版、润色与必要注释；大幅扩写按本人明确要求进行。补充内容与原话分开，文章的修正不等于原文早已包含相同结论。
- 新主题使用同一文件名，例如 `seed/新主题.md` 对应 `articles/新主题.md`，并在本表补充一行。
- 只有原文时先放入 `seed/`，文章栏标注“待整理”，不创建空白文章或失效链接。
- 两边文件均提供返回目录和互相跳转的入口。正文中的具体主张仍须结合来源及写作阶段判断。
