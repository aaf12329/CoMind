首先我们先抛弃那些花里胡哨的IDE或者集成开发环境

真男人就是应该豪起来
人生不过三万天，能豪一天是一天

so我在此发出宣言，真男人就该用notepad或者echo

所以对于python我们要知道python在哪里选择你python本体的python.exe  Ctrl+Shift+C（就得这麽豪）

然后win+r 召唤出我们的神秘小黑框(如果你想再豪一点color 0A)
把我们刚刚复制的两边的点去掉然后加上 -m venv myvenv

然后就是myvenv\Scripts\activate.bat    （进入环境）

pip install  ……（你要下载的东西）如果要加源后面加 -i 文件源网站

然后一些基础操作
mkdir 文件夹名\文件夹名\…………

type nul > 文件名.文件类型
比如  type nul > Hello.py  就是创建一个py文件

写入:
notepad 文件名.文件类型
或者
echo 内容 > 文件名.文件类型
但是注意echo>是覆盖式写入，echo>>是追加写入

然后确认在环境中python 文件名.py
其他语言也有类似的操作

==================================================
真男人补充包（后补的，越补越豪）
==================================================

1. notrpad 到底是手滑还是故意的我不问，但小黑框只认 notepad

2. 激活成功是有暗号的：提示符前面会多一个 (myvenv)
   看见它，说明你已经在环境里了；没看见，说明刚才那行复制漏了

3. 真男人也要会撤退：deactivate
   一直挂在环境里，哪天真装崩了都不知道崩在哪

4. 找 python 别一条条翻文件夹，直接 where python
   要是第一个蹦出来 WindowsApps\python.exe，恭喜，那是微软放的假人，
   0 字节，专门骗你去逛应用商店。真男人直接上绝对路径。

5. 装包的真男人三件套：
   pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple   （换源，快）
   pip list                                                       （看看装了啥）
   pip freeze > requirements.txt                                  （把家底记下来）
   换电脑一条 pip install -r requirements.txt 原地复活

6. 更稳的写法是 python -m pip install ……
   因为电脑里可能躺着三个 python，pip 说不定装到别的叔叔裤兜里去了

7. 小黑框基础四件套：
   dir             看看这层有啥
   cd 文件夹        进去
   cd ..            出来
   cls              擦干净（真男人擦屏幕也豪）

8. 路径带空格就拿引号夹住，不然它只认前半截

9. 中文乱码就 chcp 65001，一行解决，别去改系统区域设置

10. 程序跑飞了 Ctrl+C，别拔电源，那是上个世纪的真男人

11. 报错从下往上看，最后一行才是凶手，上面全是案发现场

12. echo 写多行代码属于自虐，转义符能把你送走；
    而且 echo 写中文是按 GBK 存的，Python 按 UTF-8 读，直接给你看 UnicodeDecodeError
    所以中文老老实实 notepad，豪不等于蠢

13. 跑脚本要在文件所在目录跑，或者写全路径，别在黑框里深情呼唤一个不存在的文件

14. 装了多个 python：python -V 看版本，py -0p 全列出来，py -3.10 点名要人

15. 快捷键也是豪的一部分：Tab 补全、↑ 上一条、F7 历史命令

16. 最后一条，最不豪但最重要：
    myvenv 别交、别传、别塞网盘，那玩意几百兆；
    交作业交 py + 数据 + 结果，别交整个硬盘
