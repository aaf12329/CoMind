## 批量重构操作

仅用于工程批量重构；学习资料的验证范围仍以对应规范及当前任务为准。

- 🟡 **批量重构操作要点**（血泪教训，可直接照做）：
  - 用 **AST 定位**重复块（函数 / 赋值）比肉眼可靠：`ast.parse` 取 `lineno / end_lineno`；
  - **先按原文件行号删块，再做文本替换**——替换会改变行数，替换后再按旧行号删会删错行；
  - 文本插入代码块时**每行都要带换行符**，否则会与前一行粘连成语法错误；
  - 注解赋值（`x: dict = {}`）在 AST 里是 `AnnAssign` 而非 `Assign`，扫漏会留下死代码；
  - 改完**三件套缺一不可**：全部受影响文件 `ast.parse` + 跑测试套件 + 运行时冒烟。

## 返回结构与文档字符串

原工程架构 §05 的 Python 表达方式保留如下；其他语言不照搬 `dict` 或 docstring：

- 🔴 一个模块对外**只返回约定的形状**（统一 dict / 数据类），调用方按契约解包；
  字段名一旦发布就不改（要扩展就加新字段，不改旧字段语义）。
- 🟡 契约写进模块文件头的 docstring；改契约 = 一次明确的提交（含所有调用点同步）。
