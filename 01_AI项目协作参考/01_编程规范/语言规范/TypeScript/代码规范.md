# TypeScript 代码规范（读取入口）

> 2026-10-11 建立分类入口；2026-10-25 补充个人临时草案的采用入口。

适用入口：`.ts`、`.tsx` 及 TypeScript 项目。

- 工程项目读取 [工程架构规范](../../工程架构规范.md)。
- 学习代码读取 [学习资料代码规范](../../学习资料代码规范.md)，不自动继承工程分层与重复消除要求。
- 修改仓库或提交时读取 [提交与协作规范](../../../02_提交与协作规范.md)。
- LLM / Agent 类项目另读 [专项规范](../../专项规范/LLM_Agent项目规范.md)。

当前没有另设一份 TypeScript 专属条款；Python 的 AST、自测入口与文档字符串写法不直接套用。

项目需要采用个人临时排版、调用结构等写法时，明确引用 [JavaScript 临时草案](../JavaScript/代码标准_临时草案.md) 中对 TypeScript 的适用范围；类型说明优先使用 TS 原生声明。未明确采用时，仍按上面的工程或学习规范执行，不自动启用草案。
