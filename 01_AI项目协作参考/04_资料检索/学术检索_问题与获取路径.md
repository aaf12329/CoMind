# 学术文献检索 —— 付费墙、限流、反爬的问题与获取路径

> **本文档可移植**：任何 Windows + Git Bash 环境下的 AI 助手都能直接复用；
> 目标：下次做"找论文 + 拿全文"任务时，不重复撞限流、不误判"图书馆太严"、
> 不把时间烧在盗版站上。来源：2026-09-30 检索"生物炭吸附铅"文献的踩坑复盘。

---

## 0. 参考机环境事实（2026-09 实测；换机器先照此探测）

| 项 | 值 |
|---|---|
| Shell | Git Bash (msys, Windows 10/11) |
| **不可用** | `python`（商店占位 stub）——URL 编码别指望它，手工 `+`/`%XX` 编码 |
| **可用** | `curl` (mingw64)、`grep -oE`、`sleep` |
| **关键坑** | 部分站点 HTTPS 握手失败（curl exit 35）→ **加 `--tlsv1.2` 可解**（实测 UF 官网、mdpi-res.com 均如此）|
| 反爬拦截 | 大学数字馆藏（digitalcommons）、mdpi 主站直接 403；换 UA 无效，**别死磕** |

## 1. 工具链与分工 ★

| API | 用途 | 速率表现（实测） |
|---|---|---|
| **Crossref** `api.crossref.org/works` | 题录核实（DOI/期刊/卷期页/作者）的**唯一权威** | 全程没限流，随便查 |
| OpenAlex `api.openalex.org/works/<doi>` | 单条题录 + OA 状态 | 单条稳定；**search 端点极易 429**（retryAfter 30-40s）|
| Unpaywall `api.unpaywall.org/v2/<doi>` | 合法免费全文判定 | 稳定 |
| Semantic Scholar `graph/v1/paper/DOI:<doi>` | openAccessPdf 字段（能搜到 Unpaywall 漏掉的作者自存档） | 限流最凶，请求间 `sleep 5` |
| 机构库（DSpace 7） | `…/server/api/discover/search/objects?query=` 入手 | 稳定；但很多记录**仅元数据无全文** |

**分工原则**：Crossref 负责"题录对不对"，Unpaywall/S2 负责"有没有免费全文"，
机构库 REST 负责"仓储里到底有没有文件"（JS 单页站直接打它的 `/server/api/`）。

## 2. 限流与降级（本次的坑）

- OpenAlex search 连续触发 429（提示 retryAfter 31-40s）→ **`sleep` 到点再试**，
  加 `mailto=` 进"礼貌池"；批量任务优先用 Crossref（它顶得住）。
- Semantic Scholar search 也 429 → 单条按 DOI 查 + `sleep 5` 串行。
- **一次检索会话的合理节奏**：题录核实（Crossref 随便查）→ OA 判定（Unpaywall 一批连查没事）→
  S2 兜底（串行慢查）→ 机构库（站点各异，见 §3）。

## 3. 机构库全文挖掘手法（DSpace 7 系）

JS 单页站（Angular `ds-app` 桩页）没有可直接抓的 HTML，但 REST API 全裸奔：

```
① handle 跳转桩页 → 真实域名: curl -sL -o /dev/null -w "%{url_effective}"
② 搜索条目: /server/api/discover/search/objects?query=<标题关键词>
③ 条目详情核题: /server/api/core/items/<uuid>
④ 查附件: items/<uuid>/bundles → 找 ORIGINAL bundle → …/bitstreams
⑤ 下载: /server/api/core/bitstreams/<uuid>/content
```

**注意**：不少记录只有 SWORD bundle（纯存档元数据）——**表示该记录没有全文文件**，
Unpaywall 标 OA:true 也只是指向这个空记录，别反复重试。
老版 DSpace（bitstream URL 直出）与新版走法不同，先看桩页特征。

## 4. 题录核实的纪律 ★（本次最大教训之一）

- **搜索引擎/AI 记忆给出的 DOI 必须按 DOI 反查 Crossref 验证**——本次凭记忆
  写错的 DOI 解析出了两篇完全无关的论文（同名期刊不同文）。
- Crossref 修正法：`query.bibliographic` 搜不准时，改用
  `filter=container-title:<期刊>,from-pub-date…` + `query.author` 组合过滤，
  或 Elsevier 用 PII 反查：`filter=alternative-id:<PII>`。
- 反查不出**就老实标"待核实"**，不要拿存疑题录充数。

## 5. PDF 下载与校验

```bash
curl -sSL --tlsv1.2 -o file.pdf "<url>" -w "HTTP:%{http_code} size:%{size_download}\n"
head -c 5 file.pdf        # 必须是 %PDF-；HTML 错误页开头是 <!DOC
```

- 🔴 **循环下载严禁复用同一临时文件名**——本次第一个成功文件被第二个 403 响应
  覆盖，险些交付坏文件。每 URL 独立文件名，或下载完立即 `mv` 并校验。
- 交付前逐个校验 `%PDF` 头 + 文件大小，成对记录（文件名 ↔ 来源 URL）。

## 6. 拿不到全文时：合法路径优先级 ★

先确认事实再下结论——**老文献没有免费全文 ≠ 图书馆管得严**：
付费墙在出版商手里，作者当年没自存档（Unpaywall/S2 双确认后即可死心）。

1. **机构订阅**：校园网 IP 内直接点 DOI；校外走 VPN/WebVPN 或出版商页面的
   "Sign in via your institution"（国内高校多已接入 CARSI）。
2. **文献传递**：NSTL / 馆际互借，费用低、一到两天。
3. **邮件联系通讯作者**：附机构与用途，成功率高。
4. **ResearchGate "Request full-text"**：作者本人合法提供。
5. **Google Scholar 手动浏览**：右侧偶尔挂作者自传的合法副本（API 查无 ≠ 浏览没有）。
6. ❌ **Sci-Hub / LibGen 类站点不碰**：侵权 + 恶意文件风险。

## 7. 复用工作流（直接照抄）

```
① WebSearch/API 初筛候选文献
② Crossref 按 DOI 逐条核实题录（记忆中的 DOI 一律先验）     ← 不限流，放心查
③ Unpaywall 批量判 OA → S2 串行兜底 → 机构库 DSpace REST 挖仓
④ 有免费全文：--tlsv1.2 下载 + %PDF 头校验 + 改正式文件名
⑤ 无免费全文：列 DOI 清单 + 按上表优先级给获取建议
⑥ 产出 .md 清单（含机构、要点、下载状态、待核实线索单列）
```

**本次成果**：2 篇全文 PDF + 10 篇题录清单 + 1 条待核实线索；8 篇付费墙文献
经 5 个渠道确认无合法免费全文，属出版商版权约束而非检索方法问题。
