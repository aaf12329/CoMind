# 前端学习资料

从已有的 C / Python 经验进入 JavaScript、TypeScript 与 React。先分清语言、运行环境、工具和框架，再沿着项目追调用关系与数据流。

## 从哪里开始

| 想弄清什么 | 阅读 |
|---|---|
| JS、TS、浏览器、Node、npm、Vite 分别干什么 | [语言运行与工程工具](语言运行与工程工具.md) |
| let / const、类与实例、this、bind、箭头函数 | [JavaScript 基础](JavaScript基础.md) |
| 学习先后顺序、每一步要完成什么 | [JavaScript 科技树与学习清单](JavaScript科技树_学习清单.md) |
| CSS 怎样按父子、后代与兄弟关系选择元素 | [CSS 选择器](CSS选择器.md) |
| React 的文件职责、事件调用、状态与画面如何衔接 | [React 教程：调用关系与数据流](React教程_调用关系与数据流.md) |
| 对照一个能运行的多文件项目 | [React 计数器示例](示例/react-counter-demo/README.md) |
| 明确采用个人临时写法约定 | [JavaScript 规范入口](../../01_AI项目协作参考/01_编程规范/语言规范/JavaScript/代码规范.md) → [临时草案](../../01_AI项目协作参考/01_编程规范/语言规范/JavaScript/代码标准_临时草案.md) |

建议先读运行工具和 JS 基础，再把 CSS 与原生页面练习接起来，最后对照 React 计数器。学习清单中的勾选状态保留原状，不因本次整理自动标成已掌握。

目录、组件嵌套、函数调用、模块依赖与数据流各表达不同关系。画图时给箭头标明含义，不能拿一棵文件树代替全部解释。
