# 01 线性回归 —— 整个深度学习世界的第一块砖

## 这是什么

世界上最简单的"学习机器"：`ŷ = w·x + b`，两个参数，从带噪声的数据里把规律学出来。
它简单到不配叫"模型"，但**反向传播的全部思想已经装在里面了**——后面 05 个文件夹
的所有东西，本质上都是这一块的放大版。

## 它教你的三件事

1. **损失函数**：`L = mean(½(ŷ−y)²)`，衡量"预测得有多离谱"。乘 ½ 纯粹是为了
   求导时把平方的 2 抵掉，让导数干净。
2. **反向传播的种子**：`dL/dŷ = ŷ − y`。整条反向链的第一个梯度就这么多——
   误差本身就是梯度。全系列每个模型里都有一个它的变体
   （softmax+交叉熵的种子是 `p − onehot(y)`，角色完全一样）。
3. **数值梯度检查**：用 `(L(w+ε)−L(w−ε))/2ε` 做差分当质检员。手推的梯度永远
   可能推错，差分不会骗人。这套质检流程后面每个文件夹都在用。

## 自测题

1. 为什么 loss 永远降不到 0？（答：数据自带 0.3 的噪声，那是模型吃不掉的部分）
2. 为什么损失函数要乘 ½？（答：平方求导出 2，乘 ½ 抵掉）
3. 如果把学习率调到 10 会发生什么？（动手试：loss 会震荡甚至发散——步子太大）
