# 让工作台随你而行：重装恢复与新机迁移

换一套系统，换一台电脑，熟悉的工作节奏也能一起带走。

**Quick_deployment** 是一份个人开发环境恢复清单，用来记录常用软件、网站入口、编辑器插件和 AI Agent 配置。重装系统或迁移到新电脑时，沿着清单找回工具、恢复项目，再继续写代码与学习。

目前以 Windows 为主，面向 C、Python 和正在学习的 JavaScript / TypeScript，也保留机器学习、科研资料与日常工具的入口。

## 把工作环境带回来

1. **重装前留下备份**：保存代码、未提交文件、项目依赖记录、个人配置，以及需要单独迁移的数据集、模型和本地资料。
2. **恢复联网与账号**：找回网络配置、浏览器同步和常用账号，让软件下载与代码仓库可访问。
3. **恢复基础工具与语言环境**：按照网站清单安装所需工具，再按具体项目恢复编译器、Python / conda、Node.js 等环境。
4. **恢复编辑器与 AI Agent**：使用对应清单恢复插件、Skills 和 MCP，并核对新电脑上的安装路径。
5. **恢复项目并验证**：取回代码与本地备份，依据项目自己的依赖文件安装环境，运行构建、测试或最小示例。

需要先取回这份清单时，可以下载仓库 ZIP；安装 Git 后也可以克隆：

```powershell
git clone https://github.com/aaf12329/Quick_deployment.git
```

## 让清单跟上日常

- 安装或移除常用插件后，更新对应清单的版本、用途与状态。
- 更换安装目录、Profile 或 MCP 配置后，更新相关路径和恢复说明。
- 给新的 AI Agent 补充记录时，沿用 `AI插件.md` 中的预留章节。
- 清单里的版本与绝对路径是原电脑的环境快照，迁移时按新电脑调整；项目依赖以各项目的记录为准。

此仓库存放恢复说明、入口与安装记录。个人账号凭据和完整私有配置另行备份，数据集、模型和项目文件按各自的位置恢复。

愿下一次开机，熟悉的工具已在手边，思路可以接着往前走。
