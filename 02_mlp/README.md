# 02 多层感知机 MLP —— "深度"二字的全部含义

## 这是什么

`线性变换 → tanh 非线性 → 再线性变换`，夹一层 32 个神经元的隐层。
任务：两月牙二分类——**一条直线永远分不开、一层隐层轻松分开**的教科书数据集。

神经网络 = 线性变换的叠加本来还是线性的，**中间不加非线性就等于什么都没加**。
tanh 就是那个把直线"掰弯"的东西，也是"深度"有价值的原因。

## 它教你的三件事

1. **链式法则跨层传递**：反向传播从种子 `dlogits = (P − onehot(y))/N` 出发，
   先算输出层（dW2），再穿过 tanh（乘 `1 − h²`），再算输入层（dW1）——
   01 里那条一层的链，这里变成了两层的接力。
2. **tanh 的导数**：`1 − h²`。每个激活函数都要背一个自己的导数公式，
   这是它们在反向传播里的"过路费"。
3. **Adam 优化器**：梯度下降的自动挡（动量 + 自适应步长）。
   手写就十几行，论文 5.3 节同款，03/04 还会再见到它。

## 自测题

1. 去掉 tanh（或者把它换成另一个线性层）会怎样？
   （答：两层线性叠加还是线性，边界永远是直线，月牙分不开）
2. 为什么梯度检查对 b1/b2 这类一维向量也成立？（答：链式法则不关心形状）
3. 隐层加到 1024 个会更好吗？（答：训练集精度会上去，但可能把噪声也记住——
   深度不是免费午餐）
